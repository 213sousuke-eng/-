# 中学数学 計算トレーニングアプリ 設計書

日付: 2026-11-05

## 目的と利用者

- 利用者: 中学3年生（高校受験生）
- 目的: 定期テスト・高校受験に向けた計算力の強化と苦手単元の克服
- 成功の条件:
  - 学校の制限付き iPad（Safari）、スマホ、PC のどれでもエラーなく動く
  - 出題される問題の正解が常に正しい
  - 苦手単元が数字で分かり、そこを重点的に練習できる

## 前提・制約

- 学校の iPad はフィルタで外部サイトが制限されている可能性がある
  - 外部リソース（CDN・Webフォント・API通信）を一切使わない
- ログインなし。記録は端末内（localStorage）のみ
  - 端末間での記録共有はしない
- iPad Safari は 7日間アクセスがないサイトのデータを消すことがあるため、ホーム画面への追加を案内する
- 公開先: GitHub Pages（リポジトリを公開設定にする必要がある）
  - 学校 iPad で `github.io` が開けるかは事前に確認する

## 構成

単一の `index.html` に HTML / CSS / JavaScript をまとめる。ビルド工程なし。

テストしやすいように、ロジックは純粋関数として書く。同じコードを Node.js のテストからも読み込めるようにするため、JavaScript は `src/` に分割し、簡単な結合スクリプトで `index.html` を生成する。

| ファイル | 役割 |
|---|---|
| `src/math.js` | 分数・根号・多項式などの数式ユーティリティと表示用整形 |
| `src/generators.js` | 単元ごとの問題生成 |
| `src/quiz.js` | セッション管理（10問）・採点・解答入力の解析 |
| `src/storage.js` | localStorage への記録の保存と読み込み、苦手度の計算 |
| `src/ui.js` | 画面描画とイベント処理 |
| `src/style.css` | スタイル |
| `build.js` | 上記を結合して `index.html` を出力 |
| `tests/*.test.js` | Node 標準の `node:test` による自動テスト |

外部依存パッケージは使わない（Node 標準機能のみ）。

### 問題オブジェクトの形

```js
{
  unitId: "factorize",
  level: 1,                 // 1=基本, 2=受験レベル
  prompt: "x² + 5x + 6 を因数分解しなさい",
  answerType: "choice",     // "number" | "choice"
  answer: "(x + 2)(x + 3)", // choice の場合は表示文字列、number の場合は数値文字列（分数可）
  choices: [...4件],         // choice の場合のみ。正解を1つだけ含み、重複なし
  steps: ["…", "…"],        // 解き方の手順
}
```

- 数値で答える問題が複数の値を求める場合（連立方程式の x, y など）は、入力欄を複数用意する
  - この場合 `answer` は配列、`fields` に各欄のラベルを持つ
- 二次方程式の解のように答えが2つあるものは4択にする

## 単元

| 学年 | unitId | 単元 | 主な解答形式 |
|---|---|---|---|
| 中1 | `signed` | 正負の数（四則・累乗） | 数値 |
| 中1 | `linexpr` | 文字式の計算 | 4択 |
| 中1 | `lineq` | 一次方程式 | 数値（分数可） |
| 中1 | `proportion` | 比例・反比例の式 | 4択 |
| 中2 | `polycalc` | 式の計算（多項式・単項式の乗除） | 4択 |
| 中2 | `simul` | 連立方程式 | 数値×2 |
| 中2 | `linfunc` | 一次関数の式（2点・傾きと1点） | 4択 |
| 中3 | `expand` | 式の展開（乗法公式） | 4択 |
| 中3 | `factorize` | 因数分解 | 4択 |
| 中3 | `sqrt` | 平方根の計算 | 4択 |
| 中3 | `quadeq` | 二次方程式 | 4択 |

各単元に難易度を2段階用意する。

- 基本: 係数が小さい、手順が少ない
- 受験レベル: 分数・かっこ・共通因数のくくり出し・解の公式など

### 誤答選択肢の作り方

典型的なミスから作る。例:

- 符号の取り違え
- 2乗の展開で `2ab` の項を忘れる
- 係数の掛け忘れ
- √ の簡約ミス

候補が足りないときは、正解の値を少しずらしたもので補う。正解と同じ文字列は除外する。

### 数値入力の解析

- 受け付ける形: 整数、`-3`、分数 `3/4`・`-3/4`、小数（正確に等しい場合のみ正解）
- 全角数字・全角マイナス・空白は半角に正規化する
- 数値として解析できない入力は不正解にせず、「数字で入力してね」と表示して再入力させる

## 画面

1. **ホーム**
   - 学年ごとの単元一覧（各単元の正答率と解答数を表示）
   - 難易度の切り替え（基本 / 受験レベル）
   - 「苦手ミックス」ボタン
   - ホーム画面への追加の案内（初回のみ。閉じられる）
2. **出題**
   - 進捗表示（例: 3 / 10）
   - 問題文と、入力欄または4択ボタン
   - 解答直後に正誤を表示
   - 不正解のときは正解と解き方の手順を表示し、「次へ」で進む
3. **結果**
   - 得点
   - 間違えた問題の一覧（正解と手順つき）
   - 「もう一度」「ホームへ」
4. **記録**
   - 単元ごとの正答率と解答数
   - 記録のリセット（確認ダイアログつき）

## 記録と苦手復習

- localStorage のキー `chugaku-math-v1` に JSON で保存する
  - 形式: `{ units: { [unitId]: { recent: [1,0,1,...] } } }`
  - `recent` は直近20問分の正誤
- 正答率は `recent` から計算する。未解答の単元は「未挑戦」と表示する
- 苦手ミックスの出題比率: 単元ごとの重みを `(1 - 正答率) + 0.1` とする
  - 未挑戦の単元は重み 0.5
  - 重みに比例した確率で単元を選ぶ
- localStorage が使えない環境（プライベートブラウズなど）でも出題は動く
  - 書き込みに失敗しても例外を出さず、その旨を小さく表示する

## エラー処理

- 問題生成は、条件（割り切れる・0 で割らない・選択肢の重複なし）を満たすまで作り直す
  - 上限回数を超えたら、その単元の固定の予備問題を使う
- 保存データが壊れている場合は初期化する

## テスト

- **自動テスト**（`node --test`）。各単元・各難易度で 1000 問ずつ生成し、次を確認する
  - 正解が数学的に正しい
    - 方程式は解を代入して検算する
    - 因数分解は展開して元の式と一致させる
    - 平方根は数値で照合する
  - 4択に正解がちょうど1つ含まれ、選択肢に重複がない
  - NaN や Infinity、0 による割り算を含まない
  - 解答入力の解析（分数・全角・空白・不正入力）
  - 苦手度計算と保存・読み込み（破損データを含む）
- **ブラウザ確認**（Playwright）。iPad とスマホの画面サイズで次を確認する
  - ホーム → 出題 → 結果 → 記録 の一連の流れを操作できる
  - コンソールにエラーが出ない
  - 横スクロールが発生しない
