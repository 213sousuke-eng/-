# 中学数学 計算トレーニング

中学1〜3年の計算問題（11単元）を自動で作って出題する、Webアプリです。
HTML 1ファイル（`index.html`）だけで動き、外部のサイトには一切接続しません。

- 単元：正負の数、文字式、一次方程式、比例・反比例、式の計算、連立方程式、一次関数の式、式の展開、因数分解、平方根、二次方程式
- 難易度：「基本」と「受験レベル」
- 10問1セット。間違えると正解と解き方を表示
- 単元ごとの正答率を端末に記録し、「苦手ミックス」で苦手な単元を多めに出題
- 記録は使っている端末のブラウザの中にだけ保存されます（ログイン不要、ネットには送りません）

## 公開のしかた（GitHub Pages）

1. このリポジトリを **Public** にする
   （Settings → General → 一番下の Danger Zone → Change visibility）
2. **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を `main`、フォルダを `/ (root)` にして Save
3. 数分待つと、次の URL で開けるようになります
   - アプリ: `https://213sousuke-eng.github.io/-/`
   - 表示テスト: `https://213sousuke-eng.github.io/-/check.html`

## 学校の iPad で使う前に

1. まず iPad の Safari で **表示テストのページ**（`check.html`）を開き、「このページが見えれば OK」と出るか確認してください。
   出ない場合は、学校のフィルタで `github.io` が止められています。
2. 見えたらアプリの URL を開き、**共有ボタン →「ホーム画面に追加」** をしてください。
   Safari は 7日以上開かなかったサイトの保存データを消すことがあるため、ホーム画面から起動すると記録が消えにくくなります。

## 開発

Node.js 18 以上で動きます。外部パッケージは使っていません。

```sh
npm test        # ユニットテスト（全単元の問題を大量に作って答えを検算）
npm run build   # src/ から index.html を作る
npm run e2e     # ブラウザでの動作確認（Playwright が必要）
```

ソースは `src/` にあります。`index.html` は `npm run build` で作られるファイルなので、直接は編集しないでください。
